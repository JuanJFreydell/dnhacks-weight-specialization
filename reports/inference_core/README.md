# Inference-core results

This directory stores reproducible, versioned test and implementation summaries
for the Top-1 ReGLU MoE candidate. `generic.junit.xml` and `fixed.junit.xml` are
generated by the cocotb targets and retained as machine-readable proof of the
checked source revision. ASIC physical-design reports will be added here only
after the flow and SRAM-macro substitution are reproducibly configured.
