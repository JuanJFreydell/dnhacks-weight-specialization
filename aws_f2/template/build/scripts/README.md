# AWS HDK linked scripts

The AWS F2 template generated by the AWS FPGA Developer Kit contains four
symlinks from this directory into the HDK's `common/shell_stable` tree. Those
targets are part of the upstream HDK checkout rather than DNHacks source, so
the links are intentionally not tracked here: they would be broken in a
standalone GitHub clone.

To reproduce an F2 build, clone the AWS FPGA Developer Kit's `f2` branch,
create or select its `CL_TEMPLATE` custom-logic design, and overlay the
tracked DNHacks files from `aws_f2/template/`. The HDK supplies the linked
scripts and shell collateral. See `aws_f2/README.md` for the DNHacks wrapper
and register map.
